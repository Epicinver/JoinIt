# JoinIt
(LEGIT AND LEGAL) Discord account joiner

Uses Join Servers For You permission to make all authorized users join 1 server.
Just paste in the guild ID and if the bot is in the server then the user will join the server.

# INSTALL / RUN

To install all dependencies, do install.bat
To run the tool, do run.bat

Please install Cloudflared before installing.
